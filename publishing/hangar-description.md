# SmartAdmin

Smart staff assistant for Minecraft servers.

**Stop guessing. Start investigating.**

SmartAdmin helps staff teams review suspicious player behavior using risk scores, player timelines, staff alerts, watch mode, staff notes, and evidence reports.

## Honest Positioning

SmartAdmin is not a classic anti-cheat. It does not auto-ban players, does not inspect clients, and does not claim perfect xray detection.

It provides server-side signals and investigation data so staff can review behavior faster.

## Included in v0.2.0-beta

- Player risk score
- Risk levels
- Player timeline
- Suspicious mining signals
- High-value ore burst detection
- Staff alerts
- Watch mode
- Risk reset command
- Staff notes
- Evidence reports and text exports
- Top risk players command
- Basic Discord webhook alerts
- SQLite storage
- Configurable thresholds

## Commands

Use `/sa` for daily staff work.

The full command is `/smartadmin`. Aliases `/sa` and `/si` are also registered.

Investigation commands include `/sa evidence <player>`, `/sa export <player>`, and `/sa top [limit]`.

## Beta Notice

This is a beta release. Test before production use and tune the configuration for your server rules and staff workflow.
